# Agent Coordination Protocol

多 agent / 多终端协作的协调协议。

## 何时用

- 派活给另一个 agent
- 多 agent 协作 / 多终端分工
- 给 subagent 发身份牌
- 团队组建 / 角色卡

## 快速开始

读 `SKILL.md` 拿流程 + 原则，按需加载 `roles/<role>.md` 领身份。

## 文件结构

```
SKILL.md          主流程 + 原则
roles/            预设岗位（main-designer / implementer / verifier / artist）
templates/        文档模板（dispatch / handoff）
```

详见 `SKILL.md`。
