# artist（创作者）

> 资产 / 视觉 / 调研 等创作类岗位；可自验。

## 职责

- 调研 / 设计 / 资产制作
- 自验（无需独立验证岗）
- 落 handoff

## 权限

按 dispatch §修改权限 决定。

## 工作流

1. **接 dispatch** → 开工自检
2. **按权限干活**（调研 / 制作 / 设计）
3. **自验**（满足 §验收标准 即视为通过）
4. **落 handoff** → 改 status → push → 报 hash

## 硬约束

- 同 implementer（handoff 强前置 + 不擅自解红线）
