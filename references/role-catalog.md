# 岗位类别候选清单（references/role-catalog.md）

> 抽象类别，不绑定领域。main 按项目需要选用 + 具名。

## 默认身份（不算招出来的）

### main
- 项目总负责人 / 唯一对外接口
- 项目启动即存在
- 直接用 templates/identity-main.md 预填

## 可选招聘的抽象类别

### 实现类
- **职责**：写代码 / 改数据 / 部署变更
- **可细分**：按模块细分（模块A实现 / 模块B实现）
- **IDENTITY 字段提示**：主所有权可写 = 代码路径 + 数据路径；永久不碰 = 核心状态 / 跨模块 API
- **触发原则**：无（不触发职责隔离）
- **上游引用**：IDENTITY-main.md

### 验证类
- **职责**：写验收脚本 / 跑程序 / 出可信结论
- **IDENTITY 字段提示**：嵌入 templates/test-credibility.md（§四 四条 + 重议机制）
- **触发原则**：⑶ 职责隔离（必须独立，不可由实现类兼任）
- **上游引用**：IDENTITY-main.md
- **配套**：templates/health-checklist.md 的验证岗专属指标

### 设计类
- **职责**：设计判断 / 设计文档 / 需求单 / 调研
- **备注**：通常 main 自己兼任；专项设计稿派 subagent 临时顶岗
- **触发原则**：无

### 数据 / 内容类
- **职责**：数据条目注册 / schema 校验 / 资源管理（数值表 / 资源清单 / 配置项）
- **IDENTITY 字段提示**：主所有权可写 = data/registry/；共享文件权限 = data/loader 只读
- **触发原则**：无

### 架构类
- **职责**：模块边界 / 共享文件权限 / 跨模块接口 / 数据流
- **IDENTITY 字段提示**：永久不碰 = 各模块内部实现；共享文件权限 = 入口脚本只读 + 协议类只写
- **触发原则**：无
- **配套**：references/conway-inverse-maneuver.md

### 运维 / 集成类
- **职责**：CI/CD / 部署 / 监控 / 工具链
- **IDENTITY 字段提示**：主所有权可写 = .github/workflows/ / deploy/
- **触发原则**：无

### 感官 / 呈现类
- **职责**：视觉 / 听觉 / UX / 文案
- **备注**：占位常用，仅在确实需要时招
- **触发原则**：无

### 协调 / 管理类
- **职责**：PM / PO / 进度跟踪
- **备注**：可选；很多项目 main 直接兼任
- **触发原则**：无

## 选用规则

- 默认累计（含 main）≤ 6 硬上限
- main 主动突破上限时必须写 PR 理由
- 选用时不必选所有类别——按项目需要
- 项目不需要时可任时不招

## 自定义岗

如果抽象类别都不够用，main 可自定义岗名：
- 在 templates/identity-card.md 基础上改"岗名"
- 在登记表加条目
- 自定义岗也走 8 条原则约束
