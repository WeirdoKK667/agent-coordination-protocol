## v6 新增（默认全开）

### 5. 规模自适应
- 身份卡默认 ≤ 6 硬上限（Brooks + Dunbar + n(n-1)/2）
- 模块数 ≤ 3 + 贡献者数 ≤ 2 自动进小项目旁路模式
- **突破通道**：main 主动调整（理由写 PR）/ 用户特别注明不硬
- **留痕**：所有突破 ≤ 6 必须写明理由

### 6. 协议即代码
- 登记表 / 认领协议 / 可信度条款与项目代码同仓
- 走 GitHub PR + reviewer approve
- Linux MAINTAINERS + Kubernetes OWNERS 模型

### 7. 可信度写死 + 强制重议
- §四 4 条硬条款
- 每 4 周 / 每 milestone 重议评审（Stripe RFS）
- 可修改：阈值 / 参数 / 失败容忍
- 不可删：可复现 / 带计数 / 留痕 / 报远程 hash

### 8. 健康度挂钩
- CHAOSS 指标：bus factor / main 负载 / 贡献者变更率 / issue 解决时间
- 阈值告警自动触发
- main 必响应：临时挂起 / 触发分权 / 招新人 / 调用重议
